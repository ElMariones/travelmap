## 1. What the app is

Log the countries you've been to; watch your world fill in with colour. The design goal
is that logging a place takes under ten seconds and is never more than two taps away.
Everything else — stats, regions, friends — supports that loop rather than competing
with it.

The map is the hero. Stats and profile are secondary tabs.

## 5. Data flow

```
Supabase ──► AuthService ──► SessionStore ──► (userID)
                                               │
countries.geojson ──► GeoDataService ──► VisitStore ◄── VisitsService ──► Supabase
                                               │
                            WorldMapScreen · StatsView · ProfileView
```

`VisitStore` is the only thing views read visit data from. **Percentages are always
derived, never stored** — `progress(for:)` computes them from the bundled reference set
against `visitedCountryCodes`, so there is no counter that can drift.

## 6. The map

`CountryMapView` wraps `MKMapView` directly rather than using SwiftUI's `Map`, because
the fill-in effect needs `MKMultiPolygonRenderer`: one country can be recoloured in place
without rebuilding the other 235.

- One `MKMultiPolygon` overlay per country, added at `.aboveRoads` so system labels stay
  on top. The ISO code rides on the overlay's `title`.
- `applyVisitedCodes` diffs the set and only repaints what changed.
- Tap handling does its own ray-casting (`MKPolygon.contains`) in projected map space
  with a bounding-box prefilter, rather than relying on renderer paths that may not exist
  yet. Overlapping bounding boxes resolve to the tightest match.
- The base map is `MKStandardMapConfiguration(elevationStyle: .flat, emphasisStyle:
  .muted)` with POIs excluded, so the overlays carry all the meaning.

## 7. Data model and security

Five tables, all with RLS enabled: `profiles`, `visits`, `region_visits`, `friendships`,
`comments`. Full definitions in `supabase/schema.sql`.

- A Postgres trigger on `auth.users` creates the profile and its friend code, so the
  client never sees a user without one.
- `are_friends(a, b)` is `SECURITY DEFINER` — the visits policies call it, and without
  that it would re-enter the friendships policies and recurse.
- Photos live in a **private** bucket. `visits.photo_urls` holds Storage *object paths*,
  not URLs; the app makes signed URLs at display time.
- `delete_account()` is `SECURITY DEFINER` and reads `auth.uid()` internally, so a caller
  can only ever delete themselves.

## 8. Design system

`AppTheme.swift` is the normative source. Summary:

**Liquid Glass**

- Glass is the **control layer**. It floats above content and is never a content
  background.
- **Never nested.** Sheets, the tab bar and navigation bars are already system glass, so
  nothing inside them gets `.glassEffect`. Siblings inside a `GlassEffectContainer` are
  fine and are how shapes blend into each other.
- **`.regular`** is the only safe choice over unpredictable content — the map, where the
  user may be over pale ocean or dark terrain. It brings its own legibility handling.
- **`.clear`** does not. It is used exactly once, on the landing screen, over a gradient
  the app draws *and dims itself*. That dimming is the precondition; without it, clear
  glass is not allowed.
- Tint is reserved for the single primary action so it keeps meaning something.

**Motion**

- Springs, not durations. A spring absorbs a new target mid-flight, which is what makes a
  re-tap during an animation feel answered rather than queued.
- `AppTheme.Motion`: `snappy` (state flips), `bouncy` (things appearing), `gentle`
  (ambient), `morph` (glass shapes).
- Zoom transitions on the add-visit paths. They stay interruptible — do not add
  `interactiveDismissDisabled` except while a save is genuinely in flight.

## 9. Hard-won constraints

Things that cost real debugging time. Do not re-derive these.

| Constraint | Detail |
| --- | --- |
| **MapKit can't show the whole world** | A flat map's camera hard-clamps at ~38,500 km out, about 95° of longitude on a portrait phone. Asking for more returns the same clamped result, in both elevation styles. The "All" chip gives MapKit's widest framing. |
| **Camera needs real bounds** | `setVisibleMapRect` in `makeUIView` runs before the view has a size. `LayoutReportingMapView` reports first layout; frame the camera there. |
| **Folder references don't flatten** | `MapData` is a folder reference, so `Bundle.url(forResource:withExtension:)` returns `nil`. Pass `subdirectory: "MapData"`. |
| **xcconfig eats `//`** | Even mid-value. `$()` no longer survives Info.plist preprocessing. Only `$(SLASH)$(SLASH)` works — verified against `-showBuildSettings`. |
| **UUID case mismatch** | Swift's `UUID.uuidString` is uppercase; Postgres `auth.uid()::text` is lowercase. Storage paths must be lowercased, or uploads fail as "violates row-level security policy" far from the cause. |
| **Two `.sheet`s on one view** | SwiftUI silently leaves one unable to present. Drive multiple sheets from one modifier and an enum. |
| **Field padding isn't tappable** | A `TextField`'s hit area is its glyphs. A tap-to-focus gesture fixes it, but must sit **behind** the field — in front it beats the field's own recognisers and swallows long-press select/paste. |
| **`.breathe` washes out** | It dips a symbol's opacity far enough that a brand mark visibly fades. Don't use it on the logo. |
| **Simulator strips the Apple entitlement** | Ad-hoc signing drops `com.apple.developer.applesignin`. Sign in with Apple cannot complete in the simulator without a real team. |
| **Text injection ignores layout and shift** | On a non-US Mac layout, injected `-` and `@` come out wrong, and capitals may be lost. For simulator UI testing, prefer credentials that are lowercase and punctuation-free. |

  -destination 'platform=iOS Simulator,name=iPhone 17 Pro' \

```bash
# Install and launch
xcrun simctl install "iPhone 17 Pro" build/DerivedData/Build/Products/Debug-iphonesimulator/TravelMap.app

```

```bash
# Regenerate the Xcode project after changing project.yml
xcodegen generate
```

```bash
# Rebuild the bundled map data (needs network + `npm i -g mapshaper`)
node scripts/build-mapdata.mjs
```

`appintentsmetadataprocessor` prints a "warning:" line that is a tool notice, not a build
diagnostic, and does not appear in Xcode's issue navigator.
